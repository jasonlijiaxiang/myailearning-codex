## 阅读与交互

- 每种阅读任务使用原生 `?view=` 地址，SSR 提供所选任务完整正文；未增强时全部链接可键盘操作，增强后启用标签页键盘控制。新搜索、问题目录、章节和练习深链携带阅读任务。
- 旧裸 hash 在脚本环境自动展开并规范化地址。fragment 不随 HTTP 请求发送，无脚本时旧裸 hash 的精确定位无法由服务器决定，原生视图链接仍提供全部正文。
- 生产无脚本测试发现空 `Suspense` fallback 把正文送入隐藏流式容器，移除该包裹并增加全部视图的 SSR 回归；不能只根据 HTML 含有目标文本宣称正文可见。
- Back / Forward 保留路由历史并恢复视图，未知 hash 不盖过 query 的任务选择。图谱探索保留历史，来源筛选解除隐藏目标并在下一次主动筛选取消旧定位状态。
- 推理说明、Hero 的知识定位和关键事实提高正文可读性。手机和窄工作区的图谱使用关系节点布局，其他图谱缩放补偿文字尺寸，完整关系说明继续邻接呈现。

## 范围与门禁

英文正文与来源文案未撰写。四个原先 aligned 的模块因中文变化诚实改为 deferred，保留既有英文基线。英文来源目录仅修正技术投影：独立文案尚不存在的中文新增来源暂不进入英文目录，既有来源按原始台账顺序保留；每个英文实际引用仍必须有独立文案和有效 canonical sourceId。

执行 `npm run check`，覆盖 lint、类型、26 项单元测试、31 项既有双语结构检查、95 项渲染与设计检查、生产构建、资源预算和来源门禁。Browser plugin 不可用，使用已安装 Chrome 与工作区提供的 Playwright 验证生产构建；未新增浏览器依赖。187 项浏览器检查覆盖 1440 / 1024 / 390 的全站入口、全部 23 个模块的桌面与手机阅读任务、三个计算器、旧深链、来源筛选和全部模块的禁用脚本阅读；另验证图谱 Back、容量算式、键盘模式切换和容量跳转返回。1024×768 与 800px 下检查图谱最终文字尺寸。无控制台错误和全局横向溢出。截图与临时脚本保存在仓库外，不进入 Git 或部署包；不同浏览器、每个长段落和全部组合状态未逐一人工审校。

日常发布只使用 GitHub main 与现有 Sites 的精确提交门禁，不运行 portable、采集、handoff 或英文发布审计。发布成功以最终 main SHA 与 Sites 保存版本和部署状态一致为准。
