# 知识库审查记录（2026-09-24 至 2026-09-26，内部）

这次审查覆盖 23 个已发布模块的路由、来源解析、证据时效、双语结构和主要阅读入口，并按机制、边界、证据与重复项逐模块复核。首轮更新了 20 个模块；后续独立复核又修订了 LLM、LLM Training 和 AgentKit 的具体判断。它不是逐句重写全部模块，也不把结构检查等同于专家审校。

## 第三轮独立复核与阅读修订

- AgentKit 固定官方快速入门实际展示 Mem0 类型记忆资源和 VeADK 的 mem0 后端示例；Mem0 产品对比不能推导 AgentKit 的默认后端、运营主体、地域或 SLA。配置文档提醒含密钥配置不要提交 Git，却不承诺平台默认从安全存储注入。已同步修订中文问答、课程、证据说明、英文对应段落及 Reference 边界。
- LLM 加入 Jamba 论文支持的 Transformer–Mamba 混合架构案例。KV Cache 是注意力层运行时状态；混合架构的容量不能按纯注意力层数直接套算。课程、问答、来源台账与英文对应段落同步更新。
- LLM Training 删除“多数客户不需要从头训练”这一无证据的比例判断，改为先证明较轻方案无法满足已冻结任务缺口；训练 Goodput 改用“每单位墙钟时间的有效训练进度”解释。
- 对 23 个模块的定义、学习路线、首道问答和首张证据卡作文字抽查。缩短预测式 AI、安全、VeADK、AgentKit 的首屏定义；A2A 重试证据卡聚焦未知写结果，并补明无可查询标识时的恢复路径；MCP 补参问答区分用户征询、采样和 roots 处理器，说明只有 `requestState` 时可直接重试；修正三处“最后”后仍有步骤的标题和 Prompt 证据卡缺字。
- 实际交互发现首页有知识条目命中时仍出现“没有直接匹配的模块”，模块问答筛选后显示相同的当前数与总数。共用组件、回归测试、建设标准和质量追溯矩阵已同步修复。

## 阅读与导航改动

- 搜索支持完整自然问题，按标题、缩写和正文相关性排序；知识层筛选按每条结果的实际相关模块生效，宽泛结果逐批显示。
- 课程、练习、问答链接定位到实际可见的独立锚点；共享阅读器在切换模式、展开问答后避开粘性栏定位。
- 术语库的精确缩写优先，术语来源不再误标为该词条的单独依据。知识图先显示可解释的跨模块机制，再按需展开术语。
- 深色模式修复阅读标签、问答、Agent 知识卡、课程展开卡和关系诊断区的浅字浅底；对应规则加入建设标准、质量追溯矩阵和设计语言回归测试。

## 验证范围与剩余问题

- 自动门禁：截至 2026-09-26，`npm run check` 通过 lint、typecheck、20 项单元测试、31 项双语结构测试、90 项渲染与设计测试、构建、资源预算及来源报告；23 个模块的英文结构审计为 4 个 `aligned`、19 个 `deferred`，公开来源过期数为 0。结构通过不等于人工内容审校。
- 浏览器人工抽查：桌面 1512px 和移动端 390×844；搜索、筛选、术语、知识图、代表性模块深链，以及深色模式下的 Agent、Security 和部分专用模块。第三轮另用正式构建验证了中英文首页知识命中、移动端问答深链与计数、阅读方式切换、Jamba 来源跳转及 390px 无横向溢出，控制台无报错。当前桌面会话无法截取新画面，因此第三轮的视觉判断限于 DOM、交互与视口尺寸；人工抽查不能证明所有状态和段落均无视觉问题。
- 19 个英文模块仍处于原有 `deferred` 状态；本次为涉及的事实段落补了英文对应表述，但这不代表整个模块已完成独立英文审校。只有原有 4 个 `aligned` 模块继续接受完整同步门禁。
- Artificial Analysis 2026-08-13 原始 HTTP 响应没有独立归档，历史精确数值无法从动态官网重建。模型雷达仅按一位小数展示，Claim 降为历史证据并写明限制；不可把这组数当作当前排名或独立验证过的趋势。
- 本次第二轮对余下 15 个模块作了重点事实、机制和证据复核；仍不是逐句专家审校。后续应按事实变化、客户问题和来源风险持续复核，不能用路由与结构通过代替内容审校。
