# 全站设计与语言复核记录

日期：2026-08-12

## 复核范围

本轮覆盖全部公开页面类型，而不是只抽查首页：

- 中文与英文首页、布局和全局导航；
- 21 个已发布模块，包括通用模板、focused 模板及 RAG、AI Agent、Prompt Engineering 三个专用中文页面；
- Questions、Glossary、References 三类双语目录；
- Knowledge Graph、Model Radar、Coding Agents 三类双语专题页；
- 334 道客户问答、140 个术语、237 条来源及其共享渲染组件。

事实、Source ID、核验日期、模块更新时间、问答 `addedAt` 和正式术语不因风格复核而改写。

## 使用的 Skills

本轮安装并固定了三个 Codex 用户级 Skill：

- `design-taste-frontend`：`Leonxlnx/taste-skill`，提交 `e988add20dab0fa97d7a76781c48961c8184288e`；
- `humanizer`：`blader/humanizer`，版本 `v2.9.1`；
- `humanizer-zh`：`op7418/Humanizer-zh`，提交 `91f3d394db8419c20d67ebe22a96cf8fee0a404b`。

`humanizer` 只用于事实与证据已经确定后的末道语言复核。`humanizer-zh` 只作为中文模板感探测器，不作为事实来源，也不允许自行补充例子、数字、时间、机构或因果关系。中文建议必须再次通过 `humanizer` 的 no-fabrication 约束和项目证据契约。

## 设计结论

统一方向为“证据优先的技术出版物”：保留现有 Mist 色彩、信息架构、表格、知识图和专业密度，强化阅读层级、可访问性和响应式行为。没有把技术知识库改造成低密度营销页，也没有为了套模板而增加图片、依赖或装饰卡片。

主要变化：

- 增加共享字号、圆角、阅读宽度、焦点和动效 tokens；
- 中文继续使用宋体出版语气，英文标题和正文使用 Geist，避免英文误继承中文字体；
- 模块章节编号改为安静的编辑标记，移除重复 kicker 和装饰性 `V2.0`；
- 手机导航改为可见的自然换行布局，模块章节导航恢复横向滚动并避免锚点被遮挡；
- Graph 与 Radar 的小字、触控区域、焦点对比和手机粘性区域得到修正；
- Graph 的手机控件和图例进入独立安全区，不再遮挡可点击节点；
- 阅读进度改用 CSS scroll timeline，章节定位改用 `IntersectionObserver`。

## 语言结论

仓库整体并不存在需要批量重写的“AI 味”。术语、来源说明、技术边界和大多数客户问答已经具体、克制，应保持稳定。本轮只处理高置信问题：

- 删除首页和目录中的泛化宣传承诺、内部编辑术语与不必要的模板句式；
- 去除英文发现问题前重复的 `Ask the customer:` 元指令，但不改问题本身；
- 修复一处产品边界说明的重复短语；
- 保留否定句、三项结构、破折号和技术枚举中承担真实逻辑的部分；
- 不对 334 道问答、140 个术语和 237 条来源做机械同义词替换。

## 可访问性与语义

- 两个语言布局提供本地化 skip link；19 个公开页面壳都在导航后提供唯一 `#main-content` 目标；
- 持久筛选按钮通过 `aria-pressed` 暴露状态；Radar 使用筛选组语义，不再冒充不完整的 tabs；
- Graph 手机侧栏关闭时使用 `inert` 和 `aria-hidden`，支持 Escape、打开聚焦和关闭后焦点返回；
- 伪表格补齐 column header、row header 与 cell 角色；共享表格补充 caption 与 scope；
- 修正代表页面的标题跨级、深色页面焦点对比、placeholder 对比和手机触控尺寸。

## 验收矩阵

自动检查包括 ESLint、生产构建、英文完整性与双语本地化契约，以及全站 HTML 回归。浏览器验收使用以下视口：

- 1440 × 900：双语首页、模块模板、三个专用模块、目录、Graph、Radar、Coding Agents；
- 1024 × 768：16 个双语代表路由；
- 390 × 844：20 个双语代表路由及 Graph、Radar、模块章节导航交互。

检查项包括单一 H1、skip target 位置、文档级横向溢出、导航溢出、章节滚动、Graph 侧栏焦点、Graph 控件遮挡、Radar 手机粘性区域和筛选状态。

## 明确保留的边界

- 中文宋体、Mist 配色和现有信息架构保留；
- 证据等级、风险和关系类型继续使用各自的语义颜色；
- 技术表格、图、密集目录和长段机制说明按知识需要保留；
- 模型快照版本、来源版本、核验日期和缺失值 `—` 不是装饰，不得按风格规则删除；
- 任何后续语言清理仍必须先核对 Claims、References、术语与日期契约。
